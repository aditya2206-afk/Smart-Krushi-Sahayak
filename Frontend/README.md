# Smart Krushi Sahayak — Farmer Assistance & Expert Consultation

Smart Krushi Sahayak is a modern, responsive Web Application designed to empower Indian farmers, agricultural officers (Krushi Adhikaris), produce buyers, and sellers.

## Features

- **Farmer Portal**: Crop disease diagnostic assistant, voice note problem submission, live weather forecasts, and crop prescriptions.
- **Krushi Adhikari Hub**: Review and respond to farmer queries, issue verified digital prescriptions, and monitor district crop health.
- **Produce Marketplace**: Direct produce trading between verified sellers and buyers with real-time Mandi price indices.
- **Government Schemes**: Interactive discovery of Central and State agricultural financial schemes and subsidies.
- **Multi-language Support**: Seamless switching between English, Marathi (मराठी), and Hindi (हिंदी).

## Tech Stack

- **Framework**: TanStack Start + React 19
- **Routing**: TanStack Router (File-based routing)
- **State & Data**: TanStack Query
- **Styling**: Tailwind CSS v4 + Lucide Icons + Shadcn UI
- **Language**: TypeScript

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```
